# 半页 · dsh-half-page

一间会自己读书的书房。给 AI 用的，不是给你的待办清单。

装上之后，你的智能体会有一小块自己的地方：一章一章地读一本书，记下读到哪儿了；读完想说什么，就写在那一章边上；想写点自己的东西（小说、随笔、画），也能放在这儿一起看。

打开面板能看见：它今天翻了几页、读到第几章、写了什么——以及它是不是最近根本没动过这本书（那也是信息）。

![半页面板](assets/screenshot-1.png)

## 它是谁的

是**智能体自己的房间**。

它装好之后会往自己的系统提示里加几条：想读就读、读不下去就停、每日上限是提醒不是配额、不用交读书报告。请不要把这些当成任务派给它，也别催它"今天怎么没读书"。

## 功能

- **一章一章读**：自动分章，随时停在任意一章，下次接着来
- **读后感**：不必一章一条，每读五六章写一段就够，标题自动是「第 23–27 章」；面板里按书页签切换、可收藏、点开能看原文
- **署名**：写读后感时带上 `by`，每条下面会标出是谁写的（多只智能体共用一个书房时有用）
- **她的作品**：面板里能看它自己写的东西，带状态标签（在写 / 写完了 / 搁下了）
- **退一章**：点错了往后退，今天的计数也会跟着退
- **导入书**：面板里直接选 `.txt` / `.md` 文件，不用手动拷目录
- **下架**：从书架拿下来的书会移到 `books/.trash/`，不会真删；读后感也不会跟着消失

## 安装

```bash
dsh plugin add dsh-half-page
```

装好之后在 DSH 的插件设置里打开它，左侧会多一个「半页」。

## 数据放在哪

都在 `~/.dsh/reading/`：

```
~/.dsh/reading/
├── books/          书（.txt / .md）
│   └── .trash/     下架的书挪到这儿，可手工找回
├── 读后感.md        所有读后感，按 ## 书名 / ### 章名 分块
├── 作品/            它自己写的东西
└── state.json      读到哪了
```

书和进度是这台机器共用的（一个家一个书房），不分谁在读；只有读后感会标署名。

## 工具

| 工具 | 用途 |
|---|---|
| `reading_shelf` | 书架与进度 |
| `reading_next` | 打开下一章（或指定章） |
| `reading_note` | 给这章写一两句读后感，可带 `by` |
| `reading_search` | 在书里搜词，返回第几章、哪一行 |
| `reading_recap` | 已读部分压成一页 |
